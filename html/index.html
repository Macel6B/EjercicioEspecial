Características de Products.html:
1. Este archivo tiene una estructura donde define el uso de CSS en el head
2. En el body se incluyen las etiquetas generales de: svg, dropdown de bootstrap, navbar de bootstrap, main y footer
3. Dentro de la etiqueta main, se encuentran 2 principales elementos: un elemento section hecha con un contenedor de bootstrap y un elemento div con contenedor de bootstrap
4. Dentro del contenedor div, se encuentran dispuestas por columnas y filas distintas tarjetas que corresponden a cada producto con características descriptivas como: nombre, descripción, precio e imagen
